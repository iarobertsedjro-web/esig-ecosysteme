========================================================================
  SITE WEB ESIG GLOBAL SUCCESS
  JOURNAL DES VERSIONS (CHANGELOG)
========================================================================

  Ce fichier consigne l'historique des versions du site.
  Format du numéro : MAJEUR.MINEUR.CORRECTIF
    - CORRECTIF : correction ou petit ajustement (1.0.0 -> 1.0.1)
    - MINEUR    : ajout de contenu ou de fonctionnalité (1.0.0 -> 1.1.0)
    - MAJEUR    : refonte importante (1.0.0 -> 2.0.0)

  À chaque nouvelle livraison, ajoutez un bloc EN HAUT de la liste.

------------------------------------------------------------------------
  VERSION 1.5.0 — 14 juillet 2026
------------------------------------------------------------------------
  REFONTE TECHNIQUE MAJEURE (préparation migration vers esig.tg)

  AJOUTÉ
    - 145 fiches de formation en pages HTML statiques indexables
      (/formations/...), générées par tools/generer-fiches.js,
      avec données structurées Course et fil d'Ariane.
    - Index du catalogue (/formations/), recherche et filtres sur les
      pages catalogue, entrées par profil sur l'accueil.
    - Page 404 avec moteur de recherche ; .htaccess complet (sécurité,
      HTTPS, cache, compression, redirections 301 des anciennes fiches).
    - Pages légales modèles : mentions légales, confidentialité,
      cookies, accessibilité, CGU (à valider par la direction).
    - Formulaires durcis : antispam honeypot, consentement RGPD,
      autocomplete, conservation des UTM, erreurs accessibles.
    - Bouton WhatsApp flottant ; suivi des conversions (GA4 configurable
      avec bannière de consentement, inactif par défaut).
    - ESIG Success Assistant : widget conversationnel (inactif tant que
      l'endpoint n'est pas configuré), base documentaire, prompt système
      anti-invention, API d'exemple (dossier assistant/).
    - Outils : generer-fiches.js, generer-sitemap.js, changer-domaine.js.
    - Documentation : README-REFONTE-ESIG.md, docs/CRM-PROSPECTS.md,
      .env.example.

  MODIFIÉ
    - Domaine canonique : https://esig.tg partout (canonicals, sitemap,
      robots.txt, Schema.org) ; bloc de migration prêt dans .htaccess.
    - Accessibilité WCAG 2.2 AA : lien d'évitement, <main>, navigation
      clavier, modale accessible, pause du carrousel, focus visible,
      prefers-reduced-motion, figure/figcaption, aria-expanded.
    - Chiffres clés inscrits dans le HTML (plus de 0 avant animation) et
      cohérents : 145 formations (calcul automatique), 18 ans (depuis
      2008) ; étudiants et insertion marqués « à valider ».
    - Performance : WebP (+ repli JPEG), preload du visuel principal,
      dimensions d'images explicites, première diapositive sans JS.
    - Suppression de tous les gestionnaires JavaScript inline
      (compatibilité Content-Security-Policy stricte).

  CORRIGÉ
    - Contenu des fiches invisible pour les moteurs de recherche
      (rendu 100 % JavaScript) : résolu par les pages statiques.
    - Incohérence 42 formations affichées / 145 au catalogue.
    - Sitemap pointant vers des pages sans contenu indexable.
